## 👩‍💻 About Me

안녕하세요. 모바일 애플리케이션 개발, 머신러닝 연구, 데이터 분석 및 클라우드 기반 서비스 개발 경험을 보유한 컴퓨터과학 전공자 김남경입니다.

**브레디스헬스케어** 디지털플랫폼팀에서 AI 개발 도구를 활용한 모바일 애플리케이션 개발과 헬스케어 데이터 플랫폼 관련 업무를 수행하고 있습니다. Android 기반 집중력 훈련 앱 '브레인오아시스'의 주요 기능을 개발하고, 기존 Unity 게임 콘텐츠의 모바일 환경 개선과 연동 작업을 진행했습니다. 또한 정식 출시와 이후 업데이트 배포 과정까지 경험했습니다.

이와 함께 알츠하이머병 연구 데이터의 표준화 및 데이터베이스 구조 설계 업무를 수행했습니다.

학부 연구에서는 Python을 활용해 유전체 데이터를 전처리하고 머신러닝 모델을 구현 및 학습시켰으며, 데이터 증강과 성능 평가 실험을 진행했습니다. 해당 연구는 ACM BCB Companion 2025 국제학술대회 논문으로 게재되었으며 공동 제1저자로 참여했습니다.

기술을 활용해 실제 문제를 해결하고, 사용자 경험을 개선하며, 실험과 검증을 통해 결과물의 완성도를 높이는 개발자가 되고자 합니다.

## 🔬 연구 및 논문

### 머신러닝 및 데이터 증강 기반 항생제 내성 예측 연구

**Arkansas State University 학부 연구**

유전체 데이터를 활용해 박테리아의 항생제 내성을 예측하는 머신러닝 연구를 수행했습니다. 데이터 부족과 클래스 불균형으로 인해 발생하는 예측 성능 저하 문제를 개선하고, 다양한 데이터 환경에서 모델 성능을 평가하는 데 중점을 두었습니다.

해당 연구에서는 **50만 건 이상의 유전체 데이터**를 활용했습니다.

**주요 수행 업무**

- Python 기반 유전체 데이터 전처리 및 K-mer 특징 추출
- Random Forest와 1D CNN 등 머신러닝 및 딥러닝 모델 구현과 학습
- SMOTE 기반 데이터 증강 기법 적용
- 데이터 증강 조건에 따른 모델별 성능 비교 실험
- 정확도, 정밀도, 재현율, F1-score를 활용한 모델 평가
- 합성 데이터가 모델의 예측 성능에 미치는 영향 분석

**주요 연구 결과**

특정 박테리아와 항생제 조합을 대상으로 한 CNN 실험에서 합성 데이터 600개를 추가한 후 예측 정확도가 **73.83%에서 96.68%로 향상**되는 결과를 확인했습니다.

*해당 수치는 특정 실험 조건에서 얻은 결과이며, 전체 박테리아와 항생제 조합에 대한 일반적인 성능을 의미하지 않습니다.*
